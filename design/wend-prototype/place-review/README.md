# 장소 전체 사진 — 검토용 시안

2026-10-15 승인·커밋 요청. 결정과 이유는 `../DESIGN_NOTES.md` ㉑에 기록. 원본은 `../app.src.html`, 브라우저용 빌드본은 `../app.html`.

## 확인 경로

여행 상세 → 감천문화마을의 `+33 / 전체 보기` → 장소 사진 38장 → 사진 탭 → 크게 보기. 뒤로가기는 크게 보기 → 장소 사진 → 여행 상세 순서.

- 일반 사진은 기존처럼 크게 보기로 바로 이동한다. 6장 이하인 장소에는 전체 보기 타일이 없다.
- 6칸 중 앞 5장은 사진, 마지막 칸은 남은 사진 수와 전체 보기 입구다. 총 38장이면 `+33`이다.
- 앨범은 해당 방문 장소의 전체 사진을 촬영 순서로 보여준다. 같은 이름으로 다른 날 방문한 장소는 분리한다.
- 종이색 배경, 고운바탕 장소명, 날짜별 색상·방문 번호를 상세에서 이어받는다. 사진은 3열, 간격 4dp, 모서리 5dp.
- 새로 열면 앨범 처음부터, 크게 보기에서 돌아오면 기존 스크롤을 유지한다. 넘긴 사진이 화면 밖이면 그 사진이 보이도록 이동한다.
- 베스트샷, 여행에서 빼기, 휴지통 결과를 사진의 고유 번호로 반영한다. 표시 장수와 크게 보기의 사진 집합을 공유한다.
- 기존 시안의 색상 이미지를 재사용한 샘플 데이터다. 실제 기기 사진이나 백엔드 연동은 없다.

## 전환

- 전체 보기 타일 → 앨범: 타일의 실제 위치에서 종이 면이 펼쳐진다. 420ms, cubic-bezier(.2,0,0,1). 첫 네 줄은 30ms씩 간격을 두고 자리 잡는다.
- 썸네일 → 크게 보기: 같은 이미지가 400ms 동안 커지고 배경은 280ms에 어두워진다. 이동하는 이미지 뒤에 원본이 중복으로 보이지 않게 처리한다.
- 돌아오기는 반대 방향. 앱 바·Escape·프로토타입의 가장자리 뒤로가기가 같은 경로를 사용한다.
- 모션 감소 시 즉시 전환한다. 전환 중 뒤로가기를 누르면 진행 중인 효과를 정리한다.
- Android 구현 시에는 방문 ID와 미디어 ID를 공유 요소 키로 유지하고, 그리드 스크롤 상태를 보존한다. 실제 이미지의 Crop → Fit과 원본 비율 처리는 이 색상 이미지 시안과 별도로 실기기 확인이 필요하다.
